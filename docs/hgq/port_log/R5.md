## Deviations from the plan

1. **`mf_lin` became `mf_org`; the `lin` variant stays.** `golden/mf_cases.py` variant `lin` is R3's simple S3 model
   (2 + 2 layers, old task flags) with masked-Linformer attention (k 64, seq 168 / 160): `test_maskformer.py` (R3) needs
   that structure (classification from layer 1). The full `linformer.yaml` model is the new variant `org`, its golden
   `mf_org.npz`. `mf_lin.npz` is deleted.
2. **Layer case names.** `lin_self` / `lin_cross` (Helen) are replaced by `lin_enc`, `lin_q_ca`, `lin_kv_ca` (kind
   `attn`, org `Attention`), which `test_jit.py` / `test_variables.py` call through their `attn` paths.
3. **Edits outside R5's files** (needed for "no xfails left"; each minimal):
   - markers removed, and the call mapping extended by `kv_sort_idx` / `x_sort_value`: `test_jit.py` (R2),
     `test_variables.py` (R3; `MUST_TRAIN` for FastLayerNorm encoders and the tail rows, `DEAD_IN_TORCH` empty),
     `test_maskformer.py` (R3, markers only);
   - `pflow_hgq.yaml` (no owner): `linformer_proj_dim: 256` -> `linformer_k: 256` (comments updated). Both
     implementations raise on `linformer_proj_dim`, so the hybrid's default training config (`main_hgq.py`) did not build
     at all. k = seq_len = 256 keeps its old sizes; the org model is the generated Polaris config;
   - `tests/keras/gen_parity_report.py` (R4): the stale `mask_bce` `inf` note (plan 3.2/6 table: drop it at regeneration);
   - `src/hepattn/keras/porting.py` (R4), `tests/keras_native/porting.py` (R2): `port_linformer` removed with Helen's files;
   - `.gitignore` (R0): `!tests/keras/golden/*.npz` (R4b deviation 5).
4. **Old-loss control gated per row.** Bugs 1 and 2 move the total matched loss by 7.9x its `maskformer.loss` tolerance
   (rtol 1e-3 of a total of 50 is loose), the mask_bce rows by 26-28x. The control asserts the 5 mask_bce rows > 10x and
   the total != torch. It uses real-like targets: with dummy targets the old formula is inf, which its cross-event
   einsum turns into NaN.
5. **5.8 output tolerances are per output, 2x measured**, not the plan's `maskformer.e2e` 5e-5 / 1e-4 (the plan says
   "re-measured"); measured max 2.86e-6. The matched losses keep the 1e-4 / 1e-3 rows.
6. **`mf_org.npz` is 8.1 MB** (4 decoder layers of outputs x 5 modes; the stored quantizer state is small). The largest
   earlier golden was 3.7 MB.
7. **`test_mf_jit.py`: 52 repeated loss terms** instead of 10 (the org model runs classification and mask at all 4 layers;
   mask has 9 EBOPs leaves with SwiGLU). The count is asserted from the task calls and leaf counts.
8. **G2 `--nodes` / `--queries` removed**: the config fixes them (160 / 150, `linformer_seq_len`). Size options default to
   the config (k 64, not the old 256).
