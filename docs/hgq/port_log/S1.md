## Deviations from the plan
- `keras_native/factory.py` is not byte-identical: `import keras` replaces `from hepattn.keras import keras` (as
  planned), the import sits in the third-party block (ruff isort), and the module docstring says it is
  backend-neutral. The code is otherwise unchanged (`git diff --no-index` shows only these lines).
- `keras_native/__init__.py` does not set or check `KERAS_BACKEND`, because the torch hybrid imports
  `keras_native.factory` through the shim. JAX is selected by the test conftest (later also by the driver).
- `scaling.FeatureScaler.transform` / `inverse_transform` return a new dict; the torch version writes into its
  argument. `VarTransform` raises `ValueError` on an unknown `type` (torch: `assert`) and on an unknown `fn`
  (torch silently applies no fn). Rule: unsupported configs raise.
- `tests/keras_native/__init__.py` exists so test modules import as `tests.keras_native.*`; lanes can reuse
  basenames from `tests/keras` without a pytest module-name clash.
