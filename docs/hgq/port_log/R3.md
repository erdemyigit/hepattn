   that rewrites the first test and drops the other two (sorting and quantized SwiGLU are covered by
   `test_pr8_layers.py`). Apply it at the R2 -> R3 merge (`git apply --3way docs/hgq/port_log/R3_evidence/proposed_test_float_parity.patch`)
   and record it in the merge log. `git apply --check` passes on `rt/r3` (also after prek's whitespace trim). The
   suite counts with and without the patch are in "Final counts" (fix round 2 measured them; fix round 1 had not).
   Fix round 2 changed the SwiGLU names in the patch's first hunk to `_x1` / `_x2` / `_glu`.
2. **8 blockers vs 7**: the 8th blocker (`lap1015_late`) is in `objective.py` (R1). R3 removes the 7 model blockers.
3. **R2-dependent gates deferred** (plan 5.1 says so): projection shapes (strict xfail in place), the raise on
   `linformer_proj_dim` / unknown keys, and the native side of the batch-of-one Linformer difference (R5 full model).
4. **Interface.** R2 had no commit when R3 ran. The plan's interface already exists in R0's stub
   (`Attention.call(..., kv_sort_idx=None)` in native `Attention` and `LinformerAttention`), so R3 calls it directly.
   The only test double is `RecordingAttention` / `MaskRecorder` in `test_pr8_layers.py`, which records the call
   arguments; it replaces no maths that R2 owns.
5. **High-spec SwiGLU error is set by the bias quantizer.** `QuantSpec` configures the weight, datalane and table
   places, not `bias`, so HGQ2's default bias quantizer (kbi b0=8, i0=2, step 1/64, `WRAP`) applies: bias error 7.8e-3
   at "high", kernel 1.9e-6, input 2.3e-5 (`R3_evidence/bias_quantizer.{py,out}`). This holds
   for every quantized leaf with a bias, also before R3. Plan owner: decide whether `QuantSpec` gets a `bias` place.
6. **`QEinsum` ellipsis (fixed in round 1).** HGQ2 0.1.9 expands `...` with letters taken from a Python `set`
   (`hgq/layers/ops/einsum.py`, `build`), and `get_config` serialises the expanded string. Measured for
   `"...d,...d->...d"` at rank 3 under PYTHONHASHSEED 0-5: `Szd`, `Vtd`, `hkd`, `Jad`, `Xmd`, `bmd`
   (`R3_evidence/fix1/qeinsum_hashseed.{py,out}`). Fix round 2 uses R4a's fixed `bnc,bnc->bnc` and folds other ranks
   to rank 3 (replacing round 1's rank-dependent `abd,abd->abd` / `ad,ad->ad`); asserted in
   `test_swiglu_leaves_and_names`, with rank-2 and rank-4 inputs against torch.
7. **Whole-model tolerance** stays at the plan's `maskformer.e2e` 5e-5 / 1e-4 (measured 7% of it), not 2x measured
   (about 1.7e-5): plan 5.8 fixes those rows and R5 re-measures them. The fix-round-1 reviewer noted it; left to R5.
8. **Mask-logit margin (plan 5.8) on the R3 fixture** (`R3_evidence/fix1/margin.{py,out}`). `layer_k.attn_mask` is
   `sigmoid(layer_k mask logit) >= 0.1` (`pred_threshold`, base.yaml; org `task.py` `attn_mask`). The plan's margin, 10x
   the e2e logit tolerance from logit(0.1), holds at layers 0-2 (20x, 4016x, 468x) but not at layer 3 (1.05x; 7 logits
   inside 10x). R5 owns the 5.8 fixture, so R3 asserts the weaker margin it can meet: every valid logit is >= 10x the
   measured torch-native error of its layer from the threshold (smallest: layer 3, 95x). R5 must pick or build a fixture
   that meets the plan's margin.
9. **SwiGLU names and keras init follow R4a (fix round 2; reverts the fix-round-1 init change).** R4a landed its hybrid
   twin first (`rt/r4` `7718022`, 20:52) with `_hidden{i}_x1` / `_x2` / `_glu`, `bnc,bnc->bnc` and per-half default
   glorot (no packed bound), so the packed hybrid dense that fix round 1 matched no longer exists. Plan 5.4 fixes the
   leaf rule but not the names, and R5 assigns goldens by leaf name, so R3 (whose file this is) now uses R4a's names,

   512 -> 2048), not the packed 0.0361. The plan owner can still choose the other rule; then both lanes change.
10. **`q_sa` core (fix round 2).** On the R2 merge, `q_sa` was built with `linformer_core="auto"`, which picks the masked
   `project` core for a self-attention build: renorm leaves and tail rows (10, 64) on E and F with exactly zero gradient

   is 9.5e-7 (q) / 8.3e-7 (valid kv) with either `q_sa` core (`fix2/probe_qsa_parity.py`, `trial_merge.txt`).
11. **R2-dependent rows are `skipif`, not strict `xfail` (fix round 2).** A strict xfail with `raises=AssertionError`
