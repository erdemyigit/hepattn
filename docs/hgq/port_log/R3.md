   and record it in the merge log. Verified: `git apply --check` passes on `rt/r3` (also after prek's whitespace trim),
   and the native suite on a scratch copy with the patch applied is green (see "Final counts").
2. **8 blockers vs 7**: the 8th blocker (`lap1015_late`) is in `objective.py` (R1). R3 removes the 7 model blockers.
3. **R2-dependent gates deferred** (plan 5.1 says so): projection shapes (strict xfail in place), the raise on
   `linformer_proj_dim` / unknown keys, and the native side of the batch-of-one Linformer difference (R5 full model).

   (`Attention.call(..., kv_sort_idx=None)` in native `Attention` and `LinformerAttention`), so R3 calls it directly.
   The only test double is `RecordingAttention` / `MaskRecorder` in `test_pr8_layers.py`, which records the call

   for every quantized leaf with a bias, also before R3. Plan owner: decide whether `QuantSpec` gets a `bias` place.
6. **`QEinsum` ellipsis (fixed in round 1).** HGQ2 0.1.9 expands `...` with letters taken from a Python `set`
   (`hgq/layers/ops/einsum.py`, `build`), and `get_config` serialises the expanded string. Measured for
   `"...d,...d->...d"` at rank 3 under PYTHONHASHSEED 0-5: `Szd`, `Vtd`, `hkd`, `Jad`, `Xmd`, `bmd`
   (`R3_evidence/fix1/qeinsum_hashseed.{py,out}`). `Dense.build` now sets an explicit equation from the input rank
   (`abd,abd->abd`, `ad,ad->ad`), asserted in `test_swiglu_leaves_and_names`; f01 (no explicit equation) fails it.
7. **Whole-model tolerance** stays at the plan's `maskformer.e2e` 5e-5 / 1e-4 (measured 7% of it), not 2x measured
   (about 1.7e-5): plan 5.8 fixes those rows and R5 re-measures them. The fix-round-1 reviewer noted it; left to R5.
8. **Mask-logit margin (plan 5.8) on the R3 fixture** (`R3_evidence/fix1/margin.{py,out}`). `layer_k.attn_mask` is
   `sigmoid(layer_k mask logit) >= 0.1` (`pred_threshold`, base.yaml; org `task.py` `attn_mask`). The plan's margin, 10x
   the e2e logit tolerance from logit(0.1), holds at layers 0-2 (20x, 4016x, 468x) but not at layer 3 (1.05x; 7 logits

   measured torch-native error of its layer from the threshold (smallest: layer 3, 95x). R5 must pick or build a fixture
   that meets the plan's margin.
